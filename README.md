# pxEnrich

**Evidence-grounded enrichment of biological metadata for public proteomics datasets**

pxEnrich addresses a major barrier to reuse of public proteomics data: biologically important metadata can be fragmented across repository records, publications, supplementary material, filenames, and processed datasets.

The project develops methods to recover, normalize, qualify, and validate disease-relevant metadata while preserving provenance and uncertainty.

> This repository contains public-facing documentation, Specific Aims workflow figures, and selected preliminary results. Development code and internal research materials are maintained separately.

## Specific Aims

### Aim 1

Develop and validate evidence-grounded reconstruction of disease-relevant metadata from heterogeneous public proteomics resources.

### Aim 2

Develop biological and evidence-based approaches for evaluating reconstructed metadata and identifying unsupported or contradictory annotations.
